# AI SLOP ― 絵コンテ（モーショングラフィックス全カット）

ナレーション音声（16:46）を文字起こし＆台本と自動アライメントし、**全カットを台詞の単語単位のタイミングに同期**させています。
時刻はナレーション音声の先頭からの秒数です（`data/timeline.json` が全205文のタイミング）。

## デザインシステム

## 使った技法（リサーチ結果から採用）

- **スクリーンライフ / デスクトップ・ドキュメンタリー**（UIの中で物語る）: フィード、メール、検索、フォーム、編集タイムライン
- **ISOTYPE / ユニットチャート**（Otto Neurath）: 49万ページ、3,749サイト、1万5000チャンネル、250万本の論文を「1個=1件」で見せる
- **キネティック・タイポグラフィ**: デコード（文字化け→確定）、マスク・ライズ、スタッガー、漢字モーフ（検索→検証）
- **アナログホラー**: VHSノイズ、CCTV、走査線、公式文書風の不気味さ、無音の間
- **データモッシュ / グリッチ**: ブロックずれ、RGB分離、ピクセル化トランジション
- **世代劣化（Generation loss）**: コピーのコピーを実際にシェーダーで反復劣化（モデル崩壊）
- **ディザリング / ハーフトーン / ASCII（グリフの海）**
- **スライム（slop）シェーダー**: 粘性のあるドリップ・ワイプ、タイトルの溶解
- **2.5Dカメラ、モーションブラー（サブフレーム積算）、被写界深度風ボケ**
- **3DCG**（three.js）: ベルトコンベア工場、床を埋め尽くす箱、無人のホール、百万体の群れ
