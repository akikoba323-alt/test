### 1本のファイルにつなげたい場合

編集ソフトなら、全部選んでタイムラインにまとめてドラッグすれば順番どおりに並びます。
ffmpeg を使う場合（再エンコードなし・数秒で終わります）：

```bash
cd video
ls ch*.mp4 | sed "s/.*/file '&'/" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy aislop_visual_full.mp4
```

## audio/ ― 効果音ステム（任意）

- `aislop_se.flac`（ロスレス）/ `aislop_se.m4a`（AAC）…どちらも中身は同じです。
- 映像と同じく **0:00 に置くだけで同期**します。ナレーションを0dBで置いたとき、ナレーションより約8dB小さく聞こえるレベルで作ってあります。
- すべてプログラムで合成した音なので、素材の権利関係はありません。いらなければ使わなくて大丈夫です。
