# AI SLOP ―― インターネットがAIの残飯で埋まる日｜モーショングラフィックス一式

ナレーション音声（16:45.98）に**単語単位で同期**した、解説動画の映像トラック一式です。
全カットをコードで生成しています（素材の権利処理が不要／何度でも再書き出し可能）。

## 納品物（`deliver/`）

| 場所 | 中身 |
|---|---|
| `deliver/video/chNN_*.mp4` | **映像トラック本体**（音声なし）1920×1080 / 30fps / H.264 / BT.709。GitHubの1ファイル100MB制限のため章ごと（長い章は `_a` `_b`）に分けています。**ch00から順に並べると0:00から全編 16:51 になり、ナレーションと完全に同期**します（ナレーション終了後に約5秒の余韻とフェードアウト）。 |
| `deliver/audio/aislop_se.flac` / `.m4a` | 映像に同期した**効果音ステム**（すべて合成音・任意・ミュート可） |
| `deliver/aislop_narration.srt` | ナレーション字幕（台本テキスト＋音声アライメントの実タイミング） |
| `deliver/chapters.json` | 章の開始・終了タイムコード |
| `deliver/README.md` | ファイル一覧・1本につなぐ方法 |

### 編集ソフトでの使い方

1. 映像トラックとナレーション音声を **両方 0:00 に置くだけ** で同期します（映像はナレーションの頭を0秒として作っています）。
2. 画面下部（y > 890px）は字幕用に空けてあります。自分の字幕・テロップをそのまま載せられます。
3. 左上の章タグ・右上の出典タグは映像に焼き込み済みです。
4. 効果音 `deliver/audio/aislop_se.flac`（または `.m4a`）も0:00に置くだけで同期します。ナレーションより約8dB小さく作ってあります。BGMも重ねる場合は、効果音トラックをさらに3〜6dB下げるとナレーションが聞き取りやすくなります。

## 作り直し方（開発者向け）

```bash
npm install
bash tools/fetch-fonts.sh          # フォント取得（OFL）
node tools/build.mjs                # バンドル
node tools/shot.mjs --from 913 --to 1011 --n 24 --sheet 4 --subs --out out/shots/x   # 静止画コンタクトシート
node tools/render_film.mjs          # 全編書き出し（区間ごとに再開可能）→ out/film/
node tools/make_srt.mjs             # 字幕
node tools/sfx_scan.mjs && python3 tools/sfx.py   # 効果音ステム
```

- 描画：ヘッドレス Chromium（WebGL2 / Mesa llvmpipe）＋ Canvas2D ＋ three.js。すべて時刻の関数なので、どのフレームからでも同じ絵が出ます。
- 同期：ナレーションを ReazonSpeech（sherpa-onnx）で文字起こしし、台本と文字単位でアライメント → `data/timeline.json`。各カットは `cue(文番号, '語句')` で台詞にぶら下がっています。
- 効果音：すべて `tools/sfx.py` で合成（サンプル音源は不使用）。
